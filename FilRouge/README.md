GOHUNT — Projet Fil Rouge

Présentation

GOHUNT est un site web de messagerie destiné aux passionnés de chasse. Il permet aux chasseurs de créer un compte, de consulter les profils des membres et de communiquer entre eux.

Ce projet a été réalisé en équipe de deux dans le cadre du cours de Conception et programmation de sites Web (8web101).

Fonctionnalités

* Inscription, connexion et déconnexion des utilisateurs.
* Gestion du profil de chasseur.
* Consultation de la liste des membres et de leurs profils.
* Envoi et réception de messages privés.
* Affichage de l’historique des conversations.
* Réinitialisation du mot de passe.

Fonctionnalité supplémentaire

Système d’évaluation des chasseurs : attribution automatique de 0 à 5 étoiles selon le nombre de gibiers abattus déclaré par l’utilisateur.

Technologies utilisées

* HTML5 : structure des pages.
* CSS3 : mise en forme.
* JavaScript : interactions et fonctionnalités.
* Supabase : authentification, profils et messagerie.
* GitHub : gestion des versions et collaboration.

Exécution du projet

1. Télécharger ou cloner le dépôt GitHub.
2. Ouvrir le projet dans VS Codium ou Visual Studio Code.
3. Lancer html/connexion.html avec Live Server.
4. Créer un compte ou se connecter pour utiliser le site.

Une connexion Internet et une configuration Supabase fonctionnelle sont nécessaires.



Projet universitaire réalisé en équipe de deux étudiants.

Objectif pédagogique

Mettre en pratique HTML, CSS, JavaScript et l’intégration d’une base de données, tout en développant un projet web collaboratif.
